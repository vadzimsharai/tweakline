Tweakline is installed

Notes on any page, and a chat with your AI that can see and change the page.

  1. Start a server next to your AI

    Ask your AI
    Install Tweakline using the AI instructions in the README: https://github.com/vadzimsharai/tweakline
    Or run it yourself
    curl -fLO https://github.com/vadzimsharai/tweakline/releases/latest/download/tweakline-server.js && node tweakline-server.js

    Using a phone?

    A phone can't reach a server that listens only on your computer. Keep it there and put an HTTPS reverse proxy or tunnel on the same machine in front of it, then give the server that domain: node tweakline-server.js --domain your.domain --no-local

    If the proxy runs in a container, add --trust-proxy so the server sees real client addresses.

  2. Paste the link it prints

  3. Open any page and tap the small tab at the screen edge

Notes, screenshots and patches already work without a server.
